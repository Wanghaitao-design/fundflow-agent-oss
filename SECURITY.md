# Security Policy

## Supported versions

The `main` branch is the supported version.

## Reporting a vulnerability

Do not open a public issue. Use the **Security** tab of this repository to open a private vulnerability report.

Include:

- the affected file or component;
- a reproduction using synthetic data;
- the impact and any known preconditions;
- a suggested fix, if available.

Never include real case data, identity information, credentials, or session databases.

## Scope

Security-relevant areas include the MCP stdio server, command hooks, path handling, the approval boundary, export behavior, and credential isolation.

## Response

The maintainers will acknowledge a report and coordinate a fix and disclosure timeline. This is a competition and research prototype; no bug bounty is offered.
