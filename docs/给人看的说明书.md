## 一、为什么有这个东西

  三句话说清：

  1. 你手上原本有一份已经开源的涉赌资金流分析代码（6363 行，GitHub 公开仓库，Apache-2.0），能吃微信、支付宝、银行账单，找赌客、代理、中转。
  2. 但它今天给不了民警：要装 Python、要敲命令，而且判人的尺度是错的——我实测 500 个清白人的账单，它点出 171 个"代理嫌疑"。
  3. 所以这个项目做的事是：把这份能算的旧代码，改造成能直接交到基层民警手上、并且算得准的东西。同时它也是你大创要拿出去答辩的东西，所以还得有能复现的成绩。

  ## 二、目标（只有一条标准）

  一个不懂 Python、不装环境、不敲命令的基层民警，拿到手能不能直接用来办案。

  具体四条硬要求（写在 AGENTS.md 最上面）：

  - 双击就开，装完不用再装别的东西
  - 把账单文件夹拖进去就出结果
  - 全程不联网、不上传，案子涉密
  - 只交三样东西：Excel 名单 / 能打印的流向图 / 能抄进笔录的段落，每条结论标"哪个文件第几行多少钱"
  - 之后再做手机端

  ## 四、还缺什么（不含糊）

  1. 判人的尺度——按"这批人里排名"定层级，人少也照标。这是最要命的一处，它正在改。
  2. 真账单——现在所有分数都是自己编的考卷刷出来的，没拿过一份真案子的账单验过。只有你能给。
  3. 双击就开的外壳——有现成 GUI 雏形，但从没验证过能开、没接到新判据表、没打成安装包。
  4. 手机端——一行代码没写。
  5. 两条自检脚本还红着（把已修好的 bug 写进了断言），它去改。
  6. 三个筛人门槛数（累计流入多少、几个人给他转过钱、跨几天）——没人定，现在只能做成可调参数。
