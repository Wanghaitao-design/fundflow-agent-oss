案由包：怎么加一个新案由

一个案由一个文件夹，里面五张表，全部是 CSV，Excel 双击就能打开改。
分析机本身不认识任何案由，它只认这五张表。

五张表

1. 01_词表.csv      备注里出现哪些词算线索
2. 02_迹象.csv      这个案由该查哪几种资金迹象，机器怎么算出来
3. 03_门槛.csv      几个人、多少钱、跨几天才算数
4. 04_话术.csv      判成某个角色时，笔录/情况说明里那句话怎么写
5. 05_附加列.csv    人员名单里为这个案由多加哪几栏

规矩

- 只搬家，不改算法。把写死在分析机里的东西挪进表里，算法一行不动。
- 搬完必须复测：agent/range/evaluate.py --split all 跑两遍，
  两份报告除了日期必须一模一样，不一样就说明搬坏了，回退重做。
- 表里"状态"这一栏只有三种写法：已有 / 没有，缺判据 / 写了没用，死数字。
  不许出现"应该可以""大概"。
- 判据不许自己编。每一行都要在"来源"里写清楚：代码第几行、或者哪份裁判文书、
  或者谁口头说的（写名字和日期）。

现在有什么

- wangdu/  网赌包，第一个样板，内容全部来自现有代码，没有新增判据。

缺的东西都在表里标着，主要是两类：
一是门槛现在多用"全案前百分之几"这种相对值，换一批人结果就变，需要换成写死的数；
二是 G15 先欠后结、G16 只赌不消费这两条还没有判据。

机器怎么读这两张表

- 词表：按"词类"取词，一行一类，词之间用斜杠分开。"状态"必须写"已有"才会被加载，
  写别的（比如"没有，等人补"）就是提案，机器不看。
- 门槛表：最后一列"可改参数"才是机器读的那一列，写成 名字=值;名字=值。
  前面几列是给人看的说明，改那些字不会改变机器行为。
- 同名参数可以在几行里重复出现，但值必须一样，不一样程序会当场报错停下来，
  不许悄悄选一个用。
- 表读不到、参数写成了文字、包目录不存在 —— 一律直接报错，
  不会退回用代码里的旧数字。宁可跑不起来，也不要悄悄用一份没人核对的词表。

换案由怎么做

把 wangdu 复制一份改名叫新案由，改完五张表，启动时设环境变量
FUNDFLOW_CASE_PACK=新包名 就行。已经实测过：只改表里的数，
不动一行代码，分析机的判据立刻跟着变（洗钱最低流水 30000 改成 200000，
引擎读到的立刻变成 200000）。

现在还没进包的东西（说实话）

- 百分位本身：70/80/90/95 这几档还是写死的。故意没搬——下一步要拿它们换成
  你们给的固定门槛，现在搬一遍、下一步再删一遍是自找麻烦。
- 洗钱嫌疑的分数线（境外笔数、原始分 25/40/30 那一套）和风险评分的权重。
- 赌客"纯充值型"那条里的净支出 0.5。
- 判定逻辑本身（金字塔分层、拓扑一致性、同人归并、各家账单怎么读）——
  这些属于分析机，本来就不该进包。
