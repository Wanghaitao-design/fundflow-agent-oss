  先看这里 · 在 Windows 11 上把软件做出来（只做一次）
  （这一份是给你看的；做好之后软件里另有一份给民警看的"怎么用.txt"）
================================================================

先说三件事

1. 这一步是"造软件"，不是"用软件"。造软件的这台电脑要联网下载东西，
   也可能要装一次 Python（脚本会自己处理）。
   造出来的软件拷到办案电脑上，那台电脑什么都不用装、不用联网。

2. 分析代码一行都没改，结果不会变。除了下载依赖，全程不联网，
   不会把任何东西传到网上。

3. 大概 5～20 分钟，大部分是等。中途屏幕可能好几分钟不动，别关窗口。


------------------------------ 怎么做 ------------------------------

第 1 步：解压
        用 360压缩 / 7-Zip / Bandizip 解压到你喜欢的位置，比如 D:\大创\
        别用 Windows 自带的双击解压（会把中文文件名弄成乱码）。
        解压完得到一个 windows-kit 文件夹，里面应该长这样
        （关键是 build-exe 要和 agent 平级，不能嵌两层）：

            大创\windows-kit\
                agent\
                gambling_analysis.py
                case_packs\
                示例账单\              ← 编的假账单，用来试跑
                build-exe\
                    1-build.bat          ← 就点这个
                    build-officer.ps1
                    requirements-build.txt
                    readme-first.txt（就是这个文件）

第 2 步：双击 1-build.bat
        - 弹蓝色窗口问"是否允许此应用对你的设备进行更改"，点"是"。
        - 如果 Windows 提示"已保护你的电脑"，点"更多信息"→"仍要运行"。
        - 屏幕会哗哗刷字，不要慌，不要关窗口。
        - 第 5 步最慢（5～15 分钟），可能好久不动，正常。

第 3 步：跑完自动弹出两样东西
        ① build-report.txt（报告，把它原样发回来）
        ② 软件所在的文件夹 build-exe\dist\fundflow\
           里面有 fundflow.exe —— 双击它就是那个软件，弹窗、有进度条。
           桌面上还会多一个"网赌资金研判"图标。

第 4 步：拿示例账单试一遍
        解压包里有个"示例账单"文件夹（里面四份是编的假账单，不是真人数据）。
        打开软件 → 选这个文件夹 → 点开始，
        应该出三样东西：1_人员名单.xlsx、2_资金流向图.png、3_情况说明.txt。
        结果放在你选的那个账单文件夹【旁边】的「分析结果」文件夹里，
        例如选的是 D:\大创\windows-kit\示例账单，结果就在
        D:\大创\windows-kit\分析结果\示例账单_日期时间\


------------------------------ 怎么拷到别的电脑 ------------------------------

把整个 fundflow 文件夹（或者 build-exe 里那个 officer-kit-开头的压缩包）
用 U 盘拷到办案电脑，解压到任意位置，双击 fundflow.exe 就能用。
那台电脑不用装 Python、不用装 Excel 插件、不用联网、不用敲命令。


------------------------------ 卡住了怎么办 ------------------------------

什么都不用查，把 build-report.txt 发回来就行，报错原文全在里面。

先说这次最容易撞的一个（2026-11-11 第一次真打包就是撞它）

  报错里出现 vcruntime140.dll / msvcp140.dll + Permission denied
  → 安全软件不许往文件夹里放这类文件（防"程序劫持"的常规设置），不是我们的包坏了。
    脚本会自己绕：先给这台电脑装微软 VC++ 运行库，再用"不带这几个文件"的方式打包，
    并把 vc_redist.x64.exe 和「缺运行库看这个.txt」放进软件文件夹。
    想彻底自带、不依赖运行库：把打包用的文件夹加进安全软件白名单再重跑一次。

三个最常见的情形：
  · 下不动东西：单位网挡外网。换手机热点，或者换一台能上网的电脑打包，
    打好的软件拷回来用（打包和办案不必在同一台电脑上）。
  · 找不到 exe / 双击没反应：多半是杀毒软件当病毒删了。
    报告最后会打印杀毒最近的报警记录。先把整个文件夹加进杀毒白名单，
    再重新双击 1-build.bat 一次。
  · 弹窗说缺某个 .dll：把那句话截图发回来。
