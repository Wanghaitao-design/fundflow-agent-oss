# 电诈/两卡判据包 v0.1（草案，未验证）

唯一出处 D = 《涉电信诈骗犯罪可疑特征报送指引》（原文已入库：资料/来源原文/涉电信诈骗犯罪可疑特征报送指引.txt，2026-11-11 从用户提供的 .doc 提取，共 25 条：开户环节 9 条、交易环节 14 条、取现环节 2 条）

指引原文自己就说了：不能靠单条特征判断，要"结合多种可疑特征综合判断"。
所以这个包的做法是：**逐条打勾、把命中的条数摆出来**，不是给一个总分。

分三档：能自动查 / 要看银行流水有没有那列 / 账单里查不到（转成《待调取材料清单》）

---

## 一、交易环节（14 条，账单里基本能查）

| 条目 | 指引原文摘要 | 怎么算 | 引擎现状 |
|---|---|---|---|
| T1 | 资金集中转入、分散转出，资金汇往多地、汇款人看着无关联 | 入度小、出度大：流入来自 ≤3 个账户，流出到 ≥8 个账户，且金额分散 | **已有**（层级/出度逻辑） |
| T2 | 分散转入、集中转出，来源多地、多为单次 | 入度 ≥8、出度 ≤3，且入金多为一人一笔 | **已有**（汇聚账户逻辑） |
| T3 | 快进快出、过渡性质明显，极短时间内过多个账户 | 收款后 24 小时内转出 ≥80%；且下游再转出 | **已有**（中转比 80%、24 小时、净余额 <15%） |
| T4 | 账户无余额或余额相对交易额过低 | 净留存 / 总流入 <15% | **已有** |
| T5 | 交易笔数短期内明显增多 | 周笔数环比 ≥3 倍且 ≥20 笔 | **没有**（现有 burst 是 5 笔/5 分钟的瞬时爆发，不是"短期陡增"） |
| T6 | 构造性交易、规避限额 | 大量单笔刚好落在 4.9万—5万、1.9万—2万 等门槛下沿；同日多笔拆分 | **没有**（很实用，可做） |
| T7 | 跨行收款并跨行转账 | 需要每笔的对手开户行 | **查不到**（微信/支付宝账单没这列；部分银行流水有） |
| T8 | 小额试探后立刻频繁或大额 | 先出现 0.01/1/10 元级小额，24 小时内出现 ≥1000 元或 ≥10 笔 | **没有**（做案底卡、买卖卡常见，值得做） |
| T9 | 长期不用的账户突然频繁或大额 | 首笔前静默 ≥90 天（需账单覆盖更久），或账户期前段静默 ≥30 天后突增 | **没有**（可做，但受"账单只拉了三个月"限制） |
| T10 | 短期频繁后突然停用 | 密集交易后静默 ≥15 天且在账单期末之前 | **没有**（可做） |
| T11 | 机构账户资金与经营范围规模明显不符 | 需要工商登记信息 | **查不到** |
| T12 | 极短时间内境内不同地区或境内外发生资金业务 | 需要每笔的地点/渠道 | **半个**：银行流水"交易地点/渠道"列有就能做，没有做不了 |
| T13 | 不同主体账户使用同一 IP/MAC，尤其境外 IP | 账单没有 IP | **查不到** |
| T14 | 多为网银、自助柜员机等非柜面交易 | 银行流水"交易渠道/摘要"列 | **半个**：渠道列存在才能统计"非柜面占比" |

## 二、取现环节（2 条）
| 条目 | 原文摘要 | 现状 |
|---|---|---|
| W1 | 银行卡在境外自助设备按取现标准限额频繁支取 | **查不到**（需 ATM 机具号和位置）；但若流水摘要里有"ATM取现/境外取款"，可统计"取现次数、境外取现次数" |
| W2 | 境内同一自助设备短时间多张卡（尤其异地卡他行卡）连续限额取现 | **查不到**（机具号账单没有）→ 进《待调取材料清单》：调取涉案卡全部取现记录的机具编号 |

## 三、开户环节（9 条）——账单里全都查不到
原文：执意开多卡 / 非居民身份证或假证开户 / 代理他人开户（尤其异地、偏远地区证件、未成年人、老年人、学生、无业）/ 陪同集中开户 / 资料虚假（地址是公共场所、电话停机空号）/ 不同主体开户资料密切关联（同时同地同址同电话且对手相同）/ 开户资金小随即取走 / 回避身份调查 / 频繁开户销户。

程序做不了这些，但程序能**替民警把这 9 条翻译成一张调取清单**（附原文条目号），并且能做两件间接推断：
- J-A：多人开户后立刻互相转账、且互相之外几乎没有交易 → 疑似同一批开出来的卡（间接支持"陪同集中开户"）
- J-B：多人的交易对手高度重叠（相同对手比例 ≥60%）→ 间接支持"不同主体开户资料关联、交易对手相同"

## 四、《待调取材料清单》要写成什么样
程序跑完自动出一页纸，逐条写：
1. 要查 T7/T12/T14 → 调取涉案账号在 XX 银行的**完整流水（含交易渠道、交易地点、对方开户行）**，时间范围 XXXX-XX-XX 至 XXXX-XX-XX
2. 要查 W1/W2 → 调取涉案卡**全部取现记录（含 ATM 机具编号、地址）**
3. 要查 D13（赌博包里那条 IP） → 调取**网银登录 IP、MAC**
4. 要查开户 9 条 → 调取**开户资料原件（含证件复印件、开户影像、预留电话地址、开户经办网点与时间、代理人信息）**
每一条后面挂上"指引原话"，民警复制就能贴进报告和协查函。

## 五、和赌博包的关系（结构说明，给以后加包用）
一个案由包 = 五张表：
1. 词表（备注关键词、境外词、金额吉利数）
2. 要查的迹象（本文每条 D1…D13 / T1…T14，各带一个判定函数名）
3. 门槛数（阈值全放一张表里，别写死在代码里）
4. 结论话术（能直接抄进笔录/报告的句子，带法条号）
5. 名单多出的列（每命中一类就多一列，并附证据行号）

通用底子（读表、认人、去重、建图、算出入、画钱流图、出 Excel）不动，换案由只换这五张表。
