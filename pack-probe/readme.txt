================================================================
  探路包 · 给办案民警（Windows 11）
  这一版不是给民警用的，是我们自己试路用的。
================================================================

先说三件事

1. 这一步跟「民警要不要装东西」不矛盾。这一步是在你自己电脑上造软件；
   造软件的那台电脑确实要装 Python，但造出来的成品拷到别的电脑上
   是什么都不用装的。现在就是要验证这句话到底是不是真的。

2. 全程不碰分析代码，一个算法都没改，结果不会变。
   也不会往外传任何东西，只有下载依赖的时候联网。

3. 大概 20 分钟，其中大部分是等。中途别关窗口。


------------------------------ 怎么做 ------------------------------

第 1 步：解压到你喜欢的位置，比如 D:\大创\
        解压完应该长这样（关键是 agent 和 gambling_analysis.py
        要跟 pack-probe 平级，不能嵌两层）：

        fundflow-probe\
            agent\
            gambling_analysis.py
            pack-probe\
                run.bat                      ← 就点这个
                probe.ps1
                requirements-officer.txt
                readme.txt（就是这个文件）

        解压请用 360压缩 / 7-Zip / Bandizip 这类，别用 Windows 自带的双击解压
        （自带的会把中文文件名弄成乱码）。

第 2 步：双击 run.bat
        - 弹蓝色窗口问「是否允许此应用对你的设备进行更改」，点是。
        - 屏幕会哗哗刷字，不要慌，也不要关窗口。
        - 第 4 步最慢，屏幕可能好几分钟不动，正常，别关。
        - 如果弹窗要装 Python，允许它装（只在你这台电脑上装）。

第 3 步：跑完会自动弹出一个记事本，是探路报告
        把这个文件原样发我：pack-probe\探路报告.txt
        它还会自动弹出一个文件夹，里面有跑出来的
        1_人员名单.xlsx、2_资金流向图.png、3_情况说明.txt，
        你自己先点开看一眼。


------------------------------ 我要知道的五件事 ------------------------------

  一、能不能打出来（有没有出现「没打出 exe」）
  二、打出来多大（报告里有一行「整个软件大小」）
  三、双击后要等几秒才动（报告里有「空跑一次花 X 秒」）
  四、Windows 自带杀毒有没有把它当病毒（报告里写了）
  五、跑出来的三样东西，你觉得民警拿去能不能直接用


------------------------------ 卡住了怎么办 ------------------------------

  什么都不用做，把探路报告.txt 发我就行，报错原文全在里面。
  最可能卡的地方是下载依赖（单位网挡外网）。这个能绕：
  换个手机热点，或者在别的电脑上下好文件拷进来。不算路走不通。


------------------------------ 多做一个小实验 ------------------------------

  跑完后桌面上会多一个图标：资金流研判-探路版。
  把一个装账单的文件夹用鼠标拖到这个图标上松手，看它会不会自己出结果。
  这个小实验最有价值 —— 它试的就是「民警以后到底怎么用它」。
  （正式版不是这样。正式版是个窗口：打开、把文件夹拖进去、有进度条、
    完了自己弹出三样东西。这个外壳等算准了再做。）
